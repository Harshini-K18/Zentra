# Zentra 🧠

Brain Training Games for All Cognitive Skills!

## About

Zentra is an interactive brain training web application featuring fun games designed to improve cognitive skills including memory, math abilities, and reaction time.

## Features

- **Memory Match** - Test your memory by matching pairs of cards
- **Math Challenge** - Solve math problems as fast as you can
- **Reaction Speed** - Test your reflexes with timed challenges
- **XP & Leveling System** - Earn experience points and level up
- **Statistics Tracking** - Monitor your progress over time

## Tech Stack

- HTML5
- CSS3 (with animations and modern styling)
- JavaScript (Vanilla)
- Google Fonts (Poppins)

## Live Server

Simply open 👉 https://zentra-project.vercel.app/ to start playing!
